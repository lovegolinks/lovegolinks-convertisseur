# lovegolinks-convertisseur
Convertisseur de liens d'agents vers Lovegobuy (code d'invitation 8T6UW8).

- Site : dossier `public/` (`index.html`, mascotte, logos).
- Logos des agents : `public/agents/<nom>.png`.
- Cloudflare met le site à jour automatiquement à chaque modification de la branche `main`.
